# 🛤️ Trilha de estudos

A ordem segue a **Carreira/Formação PHP da Alura**. Cada tópico vira uma pasta numerada em `Estudos/` e `Exercicios/` (ex.: `02-condicionais/`), e os módulos que mudam a forma do projeto geram uma nova versão em `Projetos/`.

> Preencha a coluna **Curso Alura** com o nome exato de cada curso conforme for fazendo.

## Checklist ao terminar um tópico

- [ ] Arquivos de estudo com comentários em `Estudos/NN-topico/`
- [ ] `README.md` do tópico de estudos com o resumo dos conceitos
- [ ] Exercícios resolvidos em `Exercicios/NN-topico/`
- [ ] Projeto atualizado (ou nova versão criada) em `Projetos/`
- [ ] Status atualizado aqui e na tabela do `README.md` principal
