# 🛤️ Trilha de estudos

A ordem segue a **Carreira/Formação PHP da Alura**. Cada módulo vira uma pasta numerada em `Estudos/` e `Exercicios/`, e os módulos que mudam a forma do projeto geram uma nova versão em `Projetos/`.

> Preencha a coluna **Curso Alura** com o nome exato de cada curso conforme for fazendo.

| # | Módulo | Assuntos principais | Curso Alura | Versão do projeto | Status |
|---|--------|---------------------|-------------|-------------------|--------|
| 01 | Fundamentos | variáveis, tipos, operadores, strings numéricas, `$argv` | | `01-screenmatch-cli` | 🟡 |
| 02 | Estruturas de controle e funções | `if`/`match`, laços, arrays, funções | | `02-screenmatch-funcoes` | ⚪ |
| 03 | Orientação a objetos | classes, encapsulamento, herança, interfaces, namespaces | | `03-screenmatch-oo` | ⚪ |
| 04 | Composer e boas práticas | Composer, autoload PSR-4, PSR-12, testes com PHPUnit | | `03-screenmatch-oo` | ⚪ |
| 05 | Banco de dados | SQL, PDO, repositórios, migrations | | `04-screenmatch-web` | ⚪ |
| 06 | Web e MVC | HTTP, rotas, controllers, views | | `04-screenmatch-web` | ⚪ |
| 07 | API REST | JSON, verbos HTTP, status codes | | `05-screenmatch-api` | ⚪ |
| 08 | Docker | Dockerfile, Docker Compose, ambiente de desenvolvimento | | `05-screenmatch-api` | ⚪ |

Legenda: ✅ Concluído · 🟡 Em andamento · ⚪ Não iniciado

## Checklist ao terminar um módulo

- [ ] Arquivos de estudo com comentários em `Estudos/NN-modulo/`
- [ ] `README.md` do módulo de estudos com o resumo dos conceitos
- [ ] Exercícios resolvidos em `Exercicios/NN-modulo/`
- [ ] Projeto atualizado (ou nova versão criada) em `Projetos/`
- [ ] Status atualizado aqui e na tabela do `README.md` principal
